## Why templ?

**templ** is a static site generator that stays out of your way.  Write Markdown,
add a layout template, run one command.  No Node, no bundler, no config sprawl.

- Markdown with YAML frontmatter
- Layout templates with partials
- Collections with automatic sorting
- Plain HTML + CSS output — no JavaScript required
